# App_childrenevents

Piccole app per bambini.

## Squishy Ravioli

`squishy-ravioli/index.html` è una pagina da colorare che genera squishy ravioli sempre nuovi.

- Apri il file in un browser (non serve un server).
- «Nuovo disegno» crea un raviolo diverso; ogni disegno ha un numero e riaprendolo con lo stesso numero esce uguale.
- Scegli 1 raviolo grande, 4 o 6 per foglio.
- Scrivi il nome della bambina per averlo stampato in fondo al foglio.
- Tocca il disegno per colorarlo sullo schermo, oppure «Stampa» per un foglio A4 da colorare a mano.
